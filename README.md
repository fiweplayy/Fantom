# Voxelis (HTML версия)

**Voxelis** — HTML/Canvas реализация воксельной sandbox/survival игры с процедурной генерацией, биомами, крафтом, погодой и системой сохранения.

## Запуск
1. Запустите локальный сервер в корне репозитория:
   ```bash
   python -m http.server 8000
   ```
2. Откройте в браузере: `http://localhost:8000/web/`

## Управление
- **WASD** — движение
- **Shift** — бег
- **1–6** — выбор слота хотбара
- **ЛКМ** — добыча блока
- **ПКМ** — установка блока
- **F** — переключение вида (логика для расширения)

## Сохранение
- Кнопки **Сохранить мир** и **Загрузить мир** используют `localStorage`.
- Включён автосейв (переключатель в настройках).

## Структура
- `web/index.html` — UI и разметка.
- `web/styles.css` — стили.
- `web/main.js` — логика генерации мира, инвентаря, крафта, печи и отрисовки.
