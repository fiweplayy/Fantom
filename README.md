# Voxelis

**Voxelis** — 3D sandbox/survival в воксельном стиле с процедурной генерацией, биомами, крафтом и системой чанков. Проект оформлен как полноценная базовая кодовая база для дальнейшего расширения.

## Быстрый старт
1. Установите **Godot 4.2**.
2. Откройте `project.godot`.
3. Запустите сцену `Main.tscn`.

## Управление (по умолчанию)
- WASD — движение
- Space — прыжок
- Shift — бег
- C — присед
