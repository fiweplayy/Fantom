# Voxelis — дизайн-док и технический план

## 1. Архитектура (сначала — каркас)

### 1.1 Движок и причины выбора
**Движок:** Godot 4.2 (GDScript).
- Быстрый прототипинг, открытый исходный код, встроенная 3D-рендер-система.
- Нативная поддержка сцен, удобная организация чанков и систем.
- Легко масштабировать под моддинг через data-driven файлы.

### 1.2 Структура проекта (папки и файлы)
```

├─ scenes/
│  ├─ Main.tscn          # корневая сцена
```

### 1.3 Ключевые подсистемы
- **World/ChunkManager:** генерация, хранение и подгрузка чанков вокруг игрока.
- **Chunk:** массив блоков и отрисовка через MultiMesh.
- **VoxelLibrary:** таблица блоков (прочность, дроп, свойства).
- **PlayerController:** движение, камера, статы.
- **Inventory/Crafting/Furnace:** базовые игровые системы.
- **Mobs:** базовый ИИ и дропы.
- **UI:** HUD и экраны меню (пока заготовка).

### 1.4 Основные потоки данных
1. Игрок двигается → Main передаёт позицию в World.
2. World просит ChunkManager обновить чанки.
3. ChunkManager создаёт/удаляет Chunk, генерируя данные по seed.
4. Chunk строит MultiMesh для визуализации.

## 2. Базовая версия (MVP)

### 2.1 Мир и генерация
- **Seed:** задаётся в `World` и передаётся в `ChunkManager`.
- **Биомы:** базовая высота + тип поверхности (трава/земля/камень).
- **День/ночь:** вращение DirectionalLight по времени.
- **Погода:** структура под дождь/туман, пока заглушка.

### 2.2 Блоки и ресурсы
**Типы блоков (пример):** воздух, трава, земля, камень, песок, дерево, листья, угольная руда, железная руда.
- Прочность определяется в `VoxelLibrary`.
- Дроп определяется таблицей блоков.

### 2.3 Игрок
- Передвижение: ходьба/бег/прыжок/присед.
- Камера: привязана к pivot (готово для переключения 1/3 лица).
- Статы: здоровье, голод, выносливость.
- Смерть и возрождение: сброс позиции и статов.

### 2.4 Системы крафта
**Верстак (crafting):** рецепты в `CraftingSystem`.

| Рецепт | Вход | Выход |
|---|---|---|
| Доски | 1× дерево | 4× доски |
| Палка | 2× доски | 4× палки |

**Печь (furnace):** 1 ресурс + топливо → переплавка.

| Переплавка | Вход | Выход | Время |
|---|---|---|---|
| Железо | 1× железная руда | 1× слиток | 8 сек |

### 2.5 Мобы
- **Пассивные:** wander AI.
- **Враждебные:** chase AI, атака в радиусе.
- **Спавн:** в зависимости от биома/времени (задача для расширений).

### 2.6 Боевая система
- Урон от оружия (заготовка).
- Хитбоксы: через `CharacterBody3D`.
- Анимации атаки: планируются на стадии расширений.

### 2.7 UI
- HUD (здоровье/голод/выносливость) — логика подключения.
- Меню паузы, настройки и крафт — планируются как отдельные сцены.

## 3. Расширения (после MVP)

1. **Биомы:** расширить генерацию по температуре/влажности.
2. **Пещеры:** 3D noise + карвинг в Chunk.
3. **Погода:** дождь/туман, влияние на видимость и статы.
4. **Система предметов:** data-driven JSON, иконки и модели.
5. **Сохранение мира:** чанки сериализуются на диск (region-файлы).
6. **Продвинутый ИИ:** патрули, стаи, реакции на игрока.
7. **Крафт:** расширенная сетка 3×3, станки.
8. **Сетевой режим:** синхронизация чанков и сущностей.

## 4. Идеи для улучшений
- Локальные события в биомах (бури, редкие существа).
- Структуры/руины с лутом.
- Продвинутые механизмы (редстоун-подобные схемы).
- Режим наблюдателя и креатив.

2. Открыть проект `project.godot`.
3. Запустить сцену `Main.tscn`.
