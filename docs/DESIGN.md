# Voxelis — HTML/Canvas дизайн-док

## 1. Архитектура (каркас)

### 1.1 Технологии
- **Платформа:** Web (HTML + CSS + JavaScript).
- **Рендер:** Canvas 2D.
- **Хранилище:** `localStorage` для сохранения мира.

### 1.2 Структура проекта
```
web/
├─ index.html     # UI и canvas
├─ styles.css     # оформление
└─ main.js        # логика игры
```

### 1.3 Подсистемы
- **World генератор:** чанки 16×16, псевдо‑noise по seed.
- **Biome слой:** лес/пустыня/горы/океан (шаблон для расширения).
- **Day/Night:** визуальная маска затемнения.
- **Weather:** дождь и туман.
- **Inventory:** Map для предметов.
- **Crafting:** набор рецептов.
- **Furnace:** переплавка руды.
- **UI/HUD:** бары статов, инвентарь, крафт, настройки.

---

## 2. Базовая версия (MVP)

### 2.1 Мир
- Seed задаётся пользователем.
- Генерация чанков вокруг игрока.
- Простая стратификация материалов (трава/камень/руды).

### 2.2 Игрок
- Передвижение по сетке, бег.
- Здоровье/голод/выносливость.
- Взаимодействие с блоками (добыча/установка).

### 2.3 Системы
- Инвентарь с ограниченным количеством слотов (визуально 5×N).
- Рецепты крафта (доски, палки).
- Печь для переплавки железа.

---

## 3. Расширения
1. 3D‑рендеринг через WebGL.
2. Детализированная система высот и пещер.
3. Нормальная физика и коллизии.
4. Настоящие мобы с ИИ и лут‑таблицами.
5. Мультиплеер через WebSocket.

---

## 4. Идеи для улучшений
- Биомы с уникальными структурами.
- Динамическая погода, влияющая на видимость.
- Редстоун‑подобная логика.
